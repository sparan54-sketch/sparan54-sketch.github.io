# Per-day backdrop photos
Drop a photo named `YYYY-MM-DD.jpg` here (e.g. `2027-04-01.jpg`) and that day's close-up uses it as the background, with the figurines and caption kept in front and the drawn props hidden.
Upload it with GitHub's web "Add file → Upload files" (binary is fine). A `YYYY-MM-DD.jpg.b64` text file holding a `data:image/jpeg;base64,...` URI also works (used when a binary upload isn't possible).
Portrait or landscape both work: the photo is cropped to fill the screen (object-fit: cover, centered). Keep the subject near the middle.
